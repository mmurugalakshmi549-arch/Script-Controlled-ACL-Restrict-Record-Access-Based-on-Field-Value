# Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Overview
This project implements a Script-Controlled Access Control List (ACL) in ServiceNow to restrict record access based on a specific field value.

## Objective
The main objective is to provide secure and controlled access to ServiceNow records using field-based conditions.

## Technologies Used
- ServiceNow
- JavaScript
- Access Control List (ACL)

## Project Phases
1. Brainstorming and Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development and Implementation
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Project Outcome
The project successfully controls record access based on the specified field value and helps prevent unauthorized access to ServiceNow records.
